The stub agent commands the zones at the close of each step (the step's `tick` event) instead of on the step's `scenario_state`, which raced the tick through the pipeline. Every write now takes effect from the next step, however long its BACnet round trips take, so a paced run reproduces whatever the stub's latency. On the RC plant, `hybrid_tuesday` saves 15.45 % (it was 16.87 %, with some writes in effect a step sooner).
