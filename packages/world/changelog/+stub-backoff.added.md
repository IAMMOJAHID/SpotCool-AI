The stub agent backs off from an operator. Before it writes a zone point, a release at 19:00 or at `stop()` included, it reads the point's priority array. If a slot more urgent than its own (1-9, an operator at 8) holds a value, it does not write, publishes one `decision` and one `explanation` (`stub: true`) naming the slot and its value, and tries again at the next step, so it resumes when the operator releases. It never releases a slot it did not write: a release goes out only while slot 10 still holds the stub's own value.
