`PlantProcessor` now pushes the plant's initial state as a `PlantMeasurementsFrame` stamped with the start time, right after the `StartFrame`, so every point has a value before the first step ends. `ParallelPipeline` lets a `StartFrame` out before its branches' output, so that state never arrives downstream ahead of the start. A recording holds it as record 0 (`RawRecord.index` counts the steps completed), and record k is the state after step k; `ReplayPlant.start()` returns record 0.
